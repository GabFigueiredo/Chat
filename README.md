# 💬 Simple Chat App

Uma aplicação simples de **chat em tempo real** construída com **React**, **Express**, **MongoDB** e **Socket.IO**, permitindo que usuários troquem mensagens instantaneamente via WebSockets.

---

## 🚀 Tecnologias Utilizadas

### Front-end
- React
- Tailwind
- Socket.IO Client

### Back-end
- Node.js
- Express
- Socket.IO
- MongoDB
- Mongoose
- CORS
- dotenv

---

## 📌 Funcionalidades

- 🔗 Conexão em tempo real com Socket.IO  
- 💬 Envio e recebimento instantâneo de mensagens  
- 🗂️ Persistência das mensagens no MongoDB  
- 👥 Múltiplos usuários conectados simultaneamente  
- ⚡ Atualização em tempo real sem recarregar a página
